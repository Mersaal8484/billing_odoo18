# أداة التوسيم المحلية

افتح `annotation_tool.html` في Chrome أو Edge، ثم اختر مجلد الصور مثل:

```text
D:\datameter
```

لكل صورة:

1. ارسم مستطيلاً حول شاشة القراءة.
2. اختر نوع العداد.
3. أدخل القراءة الصحيحة ورقم العداد إن وجد.
4. اضغط **حفظ توسيم الصورة**.
5. بعد الانتهاء اضغط **تصدير annotation.json**.

لا يتم رفع الصور إلى الإنترنت. بعد التصدير يوضع الملف في:

```text
meter-vision-data/annotations/ocr/
```

ثم تتم مراجعة التوسيم قبل استخدامه في التدريب. الإصدار الأول يحفظ منطقة
الشاشة؛ إضافة صندوق جسم العداد تأتي بعد اعتماد أول مجموعة توسيم.
