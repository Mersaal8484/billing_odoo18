الحالة: `لم يختبر / ناجح / فاشل / محجوب / غير منطبق`. الأولوية: **P0** تمنع الإطلاق، **P1** رئيسية، **P2** مساندة. عند الفشل يسجل رقم العيب، المستخدم، الشركة، السجل والدليل.

## شروط البدء وبيانات الاختبار

- [ ] تثبيت وترقية Core ثم Inventory ثم Prepaid ثم Operations ثم Billing ثم Portal ثم Migration دون أخطاء.
- [ ] ضبط شركتين، العملات، الحسابات، الدفاتر، المنتجات، الضرائب والتسلسلات.
- [ ] إنشاء مستخدم لكل دور: مدير، قارئ، فوترة، عمليات، مخزن، كاشير، محصل، بوابة.
- [ ] تجهيز تسلسل جغرافي كامل، فئتين ونوعين، قالبي عقد، وتعرفة شرائح بتاريخين.
- [ ] تجهيز عميل آجل وآخر مسبق، عداد قديم وجديد بمعاملين، وفترتي فوترة.
- [ ] إعداد SMS/WhatsApp ومزود STS وبوابة دفع في وضع الاختبار؛ لا بريد إلكتروني.
- [ ] أخذ نسخة احتياطية ومراقبة Cron أثناء الاختبارات المالية والجماعية.
