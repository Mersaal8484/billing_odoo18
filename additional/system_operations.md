# دليل العمليات وإجراءات النظام

## 1. المنطقة
* إنشاء منطقة
* إنشاء فرع
* إنشاء محول وربطه بالفرع
* إنشاء جهة أو خط سير وربطه بالمحول
* إنشاء خلية وربطها بالمنطقة
* ربط المحول بالخلية
* إنشاء الخلايا الرئيسية منطقة الإنتاج لاحتساب الفاقد وربط المحولات بها

---

## 2. التعريفات والفئات
* إنشاء تعرفة عامة وربطها بالمناطق
* إنشاء تعرفة خاصة وربطها بالمنطقة أو فرع محدد
* إنشاء تعرفة للقراءات الصفرية أو مرجع محدد
* إنشاء فئة مشترك رئيسية (أهالي – كبار - حكومي)
* إنشاء فئة مشترك فرعية وربطها بالفئة الرئيسية
* القطاع الرئيسي
* القطاع الفرعي

---

## 3. المشتركين
* **رفع بيانات المشترك** (فاعل - غير فاعل - موقوف)
  * تفعيل مشترك؛ وفي حالة الرصيد المرفوع غير صحيح يتم تعديله بالرصيد الصحيح من قبل المكتب الفني عبر مذكرة رسمية.
* إنشاء مشترك جديد
* إدخال استهلاك لمشترك
* تعديل الاستهلاك للمشترك
* تبديل عداد
* عمل تسوية للمشترك (ضم أو خصم)
* رصيد بداية الفترة
* تعديل خطوط الفاتورة (إضافة خط فاتورة أو إلغاء خط)
* إضافة خصم صندوق لفرع أو مرجع محدد
* إدخال العدادات إلى المخازن وتفعيل العداد من الموجود في المخازن لمنع حدوث تكرار في الإدخال

---

## 4. المستخدمين
* إنشاء مستخدم
* إنشاء صلاحيات (**Role Group**) بحسب الدور الوظيفي
* إنشاء صندوق متحصل + يومية
* إنشاء صندوق عام + اليومية
* إنشاء صناديق قيود يومية عامة وبقية الصناديق

---

## 5. أعمال تخص مدير النظام
* إلغاء القيود (إعادة إلى مسودة / تعديل القيود)
* تعديل الترحيلات وتاريخ السداد
* فتح الفترة
* تعديل القراءة السابقة – رسوم خدمات - أي رسوم أخرى

---

## 6. بقية الأعمال
* مخازن العدادات
* تطبيق القراءة والتحصيل
* ربط الرسائل
* ربط الروضة
* جميع التقارير المطلوبة
* بعد الإغلاق السنوي: عملية الاستعلام على البيانات التاريخية
